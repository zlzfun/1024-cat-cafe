# 1024 猫咖 · 任务题库（v2）

一颗毛线球，就是一个"人在用猫猫咖啡馆时会问的问题"。人类不出场，只留下一张便签（下面每道题的"便签"一栏），和取走成品时的一句回信。玩家扮演店里的猫，按便签把球解开。

- 说法都以 clowder-ai 仓库为准：`README.zh-CN.md`、`docs/TIPS.md`、`docs/faq.zh-CN.md`、`cat-template.json`、`docs/features/`。每道题最后一栏写了依据。
- 标 ★ 的 92 道已经放进样页 `scene-v4.html`（数据在 `quest-bank.js`），其中闲聊 38 道。其余是扩充用的，格式相同，可以直接加进去。
- 标"进行中"的，对应的特性在仓库里还没做完。正式活动时，建议先只用"已完成"的题。

## 九种解法

| 类型 | 玩家要做什么 | 这类题想让人记住什么 |
|---|---|---|
| 答疑 | 在对话框里选；选错会告诉你为什么，可以再选 | 猫咖怎么用：@ 的写法、拉闸词、命令、部署 |
| 派单 | 挑一只店猫、@ 它，它会自己跑过来接球，处理完递还给你 | 每只猫有能力画像，会按画像把任务交给最擅长的猫 |
| 查记忆 | 去图书馆翻对的那一架书；不知道在哪一架，就先查检索柜 | 猫咖有长期记忆：决策、教训、证据、人物、事件 |
| 几只猫一起 | 喊帮手，凑齐几只猫围在身边一起扒拉 | 天然的多猫协作（multi-agent） |
| 走流程 | 在工坊走一遍：写测试 → 跑 CI → 请别的猫 review → 过合并门禁 | 自由判断，结构化交付；main 永远是绿的 |
| 守铁律 | 有的球不能照做，正确的选项是"停下来，请人拍板" | 四条铁律；拿不准的事会 @owner |
| 挑本事 | 挑一样合适的 Skill 或工具 | 按需加载的 Skills、MCP 工具、能力市场 |
| 陪伴 | 没有错的选项，猫会照你选的做 | 猫会照顾人：健康小刹车、语音陪伴、猫的私人时间 |
| 闲聊 | 回一句：大多没有错的选项；聊到事实的，要先查（能算的直接算） | 猫不只接活儿，也陪你聊天；聊到事实不凭印象说（信源卫生） |

出题规则（样页里已经实现）：
- 第一颗是答疑，教 @ 的写法。
- 第二颗是派单，挑离玩家最近的那只店猫。
- 之后优先出玩家没见过的类型，并照顾玩家所在的位置：在工坊附近多出"走流程"，在图书馆附近多出"查记忆"，身边猫多就多出"几只猫一起"。
- 先按类型分、再在类型里挑：每类的机会差不多（闲聊多给一点），闲聊题再多也不会刷屏。
- 每张便签上都盖着渠道章："来自 飞书 / 钉钉 / 企业微信 / 微信 / 网页 Hub / GitHub / Telegram"。这样不用单独出题，也能让人知道猫在这些地方都能接球。

## 三、查记忆（图书馆）

## 四、几只猫一起

对话框列出这颗球要几个角色。喊一声"来帮忙！"，附近的猫会跑过来，各自认领一个角色，围在你身边一起扒拉；到齐了进度条才会走。

| | 便签 | 要几只 | 角色 |

## 五、走流程

## 九、闲聊

人类只是想聊两句：无聊、困、压力大、想被夸、问个事。大部分题没有错的选项，猫照你选的回一句、做个动作（追尾巴、伸懒腰、慢慢眨眼……）。
聊到**事实**的那几道有对错：能算的直接算（1024 是星期几），要查的先查（亚运会在哪儿办、明天下不下雨、最新版本号），查到的东西还要过一遍"信源卫生"——一手还是二手、是不是旧数据——出处一起给。对应仓库里的 F218（外部证据溯源与信源卫生）和 deep-research 技能（"快速事实查询，直接用 WebSearch"）。

写闲聊题的时候：
- 便签要像真的在群里、私信里会说的话，口语、短。
- 纯聊天的三个选项都对，但要各有各的样子（一个安静陪着、一个动手帮忙、一个逗你笑）。
- 聊到事实的，错的选项是"凭印象答""随便编一个""直接说不知道"，理由写清楚。
- 会过期的事实（比赛在哪儿办、版本号、放假安排）只写"去查"，不在题里写死答案；样页里亚运会那道写了答案（第 20 届，2026 年 9 月 19 日到 10 月 4 日，日本爱知县、名古屋），活动过后要换。

## 往题库里加题

样页里的格式（`quest-bank.js` 的 `QUEST_BANK`）：

```js
{id:'q-at', type:'quiz', ch:'飞书',          // ch 可以不写，不写就随机盖一个渠道章
 q:'我想同时问宪宪和砚砚，一条消息该怎么写？',
 opts:[['每只猫另起一行，在行首写 @猫名',1,'对：两只猫各占一行，就会各自接到'],
       ['一句话里写「@宪宪 @砚砚 帮我看看」',0,'写在句子中间的 @ 不会触发路由'],
       ['分两次发，一次问一只',0,'也行，但一条消息就够了']],
 tip:'at', thx:'原来要另起一行！'}
// 派单：{type:'route', ans:2（店猫编号）, done:'它回来时说的话'}
// 查记忆：{type:'memory', shelf:0～4, found:'书页上的字'}
// 几只猫一起：{type:'coop', roles:['架构','写代码','Review']}
// 走流程：{type:'flow'}；守铁律 / 挑本事 / 陪伴：同答疑，用 opts
// 闲聊：{type:'chat', opts:[[文字, 对不对, 猫回的那句话, 动作]]}，动作是猫的姿态名（meow / happy / slowBlink / knead / stretch / pounce / lie / sleep / alert……），不写就喵一声
```

写题时注意三点：
- 便签写成人会说的话，别写成考题。
- 错的选项要是"真的有人会这么做"的错法。
- 每道题最后都要落到猫猫咖啡馆的一项真实能力上，并给出依据。
