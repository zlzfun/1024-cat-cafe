改设计的时候先改这里，再改代码。

像素字体和它的授权在 `../fonts/`（见那里的 README）：店里加了新的字以后跑一次 `python3 fonts/subset.py`。

`样页/` 下是走到成品之前的过程页（scene v1–v4、猫模型从选型到定稿），连同它们当时用的代码一起冻结在那里，只做对照，成品不加载它们。
