# 登录与进店

打开网页到你的猫出现在店里，中间这一段叫"进店"。第一次来的人要在这里给猫挑个名字、扭到一只猫、学会怎么走和怎么碰东西；用同一个浏览器再来的人，直接在上次离开的地方醒来。

整段流程有两个要求：

- **别像登录页**。这个活动推的是 Clowder AI，所以进店从 Clowder AI 自己的网页开始：你在它的"添加成员"里登记一只新猫，页面一点点变成像素，你就进了猫咖。
- **越少步骤越好**。不设密码、不让人自己想名字：名字从店里给的几个里挑一个，店里保证不重名；这个浏览器记得你，就是你。

**为什么不要暗号、不让自己起名**（2026-10-06 改）：原来是自己起名 + 给项圈牌刻四个图案的暗号，换电脑用名字 + 暗号领回。为此要有名字规矩、屏蔽词、防冒充、暗号散列、输错锁定、组织者重置暗号，玩家多走一步、多记一样东西，组织者多一份活。活动只有几周，大多数人一直用自己那台电脑；真要换电脑、清了缓存，重新扭一只猫，几分钟就能把三个章再集一遍。抽奖要防一人多号，放到登记抽奖时按工号去重（见[组织者后台](组织者后台.md)），和猫的名字、登录无关。

## 一、流程

| 情况 | 经过 | 结尾 |
|---|---|---|
| 第一次来 | 加载 → Clowder AI 网页动画 → 挑名字 → 扭蛋（登记）→ 黑底引导 | 从毛线巨树上掉进一楼咖啡厅 |
| 来过，同一个浏览器 | 加载 → 加载页上一张"欢迎回来"的卡（4.5 秒后自己进店） | 在上次离开的地方醒来 |
| 换了电脑、换了浏览器、清了缓存 | 和第一次来一样，扭一只新猫 | 从巨树上掉下来 |
| 这台电脑记着别人的猫 | "欢迎回来"卡上点"不是我？换一只新猫"，确认以后直接到挑名字（不再放网页动画） | 新猫 |
| 登记完还没走完引导就关了页面 | 下次打开直接从黑底引导接着走 | 掉进店里 |

## 二、加载页

深色底，正中"1024 猫咖营业中"。下面一只小白猫追着一颗毛线球往右跑，线球滚过的地方留下一根红线，这根线就是进度条。线下面一行小字说正在做什么：把猫叫醒、搬桌椅、铺地板刷墙、把毛线球装进篮子、给巨树缠毛线、擦橱窗、点灯、看看你是不是来过。线走完，小猫扑上去。

- **进度是真的**：脚本下载完算八成，建好整家店（地图、店猫、补位的猫）到八成五，问完账号到头。脚本并行下载、按顺序执行。
- **不会一闪而过**：进度条最快也要走一秒左右，不会闪一下就没了；真正慢的时候就停在当前那一步等着。
- **出错不白屏**：有文件没加载出来，就写明是哪一个，旁边给一个"再试一次"。
- 来过的人，加载完就在这里出"欢迎回来"的卡片：你的猫（在慢眨眼），名字，毛色和项圈，上次是什么时候来的，解开过几颗毛线球。按钮"进店"上有一根慢慢走满的线，走满就自己进店；在卡片上点一下，线就停下来等你。卡片上还有一个"不是我？换一只新猫"：先问一句"换了以后，这个浏览器就不记得「芝麻汤圆」了，它也找不回来"，确认了才换。

## 三、Clowder AI 网页 → 挑名字

### 动画（约 8.5 秒，右下角可以跳过）

照着 Clowder AI 网页端（`packages/web`，浅色主题）的真实布局、颜色和文案来画。logo 直接用项目里的 SVG 路径。人类不出场：对话里说话的全是猫。

| 时间 | 画面 |
|---|---|
| 0～2 秒 | 首页。左边一列图标，接着是对话列表（"大厅"选中），右边是大厅的对话。斑斑早上说过"今天的咖啡豆到了"；接着宪宪说"店里今天要来一只新猫"，砚砚说"先在成员里登记一下，给它挑个名字"，烁烁说"我去把欢迎横幅挂上 ✨"。每句话出来之前，输入框上方先出"猫猫正在回复中…" |
| 2～3 秒 | 光标移到左下角的齿轮"设置"点一下，页面换成"设置 · 成员与运行时"：六只店猫的成员卡片，右上角"+ 添加成员" |
| 3～4 秒 | 点"+ 添加成员"，后面的页面变暗变模糊，弹出"添加成员"：成员模板、身份信息（名称、昵称、显示后缀、角色描述、头像、背景色……）|
| 4～6 秒 | 光标点进"角色描述"，敲下"1024 猫咖的新猫"；再点进"名称"，这一格亮起焦点框，光标闪 |
| 6～8.5 秒 | 整个页面一步步变成像素：先是 2、3、4 像素一格，颜色换成店里的调色板，带一点抖动；然后别的东西碎成 6 像素的块，从四周往里一块块掉下去、暗掉。只剩"名称"这一格，它从弹窗里挪到画面正中，边框从圆角变成店里对话框那种外深内浅的像素窗框。最后它又一步步变清楚，光标变成一只粉色的像素猫爪 |

动画停下的那一刻，画布上那一格和网页上的名字框在同一个位置、长得一样，接着换成真的名字框。系统开了"减少动态效果"时，整段动画不放，直接到挑名字。

### 挑名字

- 标题"给你的猫挑个名字"。那一格里显示选中的名字；下面一排六个名字牌，都是此刻还没有猫用的，第一个默认选中。
- 点一个名字牌就换成它，← → 也能挑；"换一批"再来六个，换多少次都行。
- "就叫它"，回车等于点它。不能打字，也不用查重：名字都是店里给的。

**名字从哪儿来**（前端和服务端是同一份：`js/account.js` 的 `Account.NAMES`）：

- 一个口味 + 一样点心：芝麻汤圆、焦糖布丁、抹茶麻薯、海盐可颂……口味 36 个、点心 36 个，一共 1296 个名字。两半都是挑过的词，拼出来不会冒犯人，也不会和店猫、"管理员"这类撞上，所以不需要名字规矩和屏蔽词。
- 补位的机器人用的是一个词的名字（年糕、摸鱼喵……），和这里永远不会撞。
- **不重名由服务端保证**：候选只发还没被占的；点"就叫它"以后，到扭蛋登记的那一刻才真正占下。这几分钟里万一被别人先占了，回到挑名字，写着"「芝麻汤圆」刚被别的猫挑走了，再挑一个吧"，换一批新的，扭到的猫还留着，挑好直接登记。
- 名字用完（1296 个都有猫了）之前，服务端会在前面加"小""大"再发一轮。

## 四、扭蛋 → 登记

像素画布的放大倍数按窗口高度定（一个像素 3～6 个屏幕像素），深色底，只有聚光灯下亮着。

1. **扭蛋机掉下来**：一台猫头形状的扭蛋机从上面落下，弹两下落稳。玻璃罩是猫头，顶上一块红帽子带两只耳朵；罩子里十几颗扭蛋，颜色就是店里的六种项圈色。机身上写着 1024。
2. **名字变成硬币**：刚才取的名字从输入框的位置飞向投币口，越飞越小，"叮"一声投进去。
3. **转旋钮**：字幕"转一下旋钮"，旋钮一直轻轻晃着。按 E、空格，或者在画面上点一下都行。旋钮转一圈，咔哒咔哒响，罩子里的扭蛋跟着晃，一颗掉进出蛋口，翻盖打开，扭蛋骨碌碌滚出来。
4. **扭蛋蹦到跟前**：它一跳一跳地蹦到画面中间，越蹦越大；扭蛋机往左边让开。扭蛋晃三下，一下比一下晃得厉害。
5. **裂开**：上半个壳转着圈飞出去，下半个沉下去淡掉，光线四射、碎屑乱溅，你的猫开心地蹦一下，然后端端正正坐好。
6. **卡片**："扭到了"，名字，毛色 · 项圈颜色，平时是什么表情（比如"舌头老是忘了收"）。两个按钮："就是它了"，和"再扭一次（还有 2 次）"。
7. **再扭一次**：扭到的猫不走，往左挪一挪让出位置；扭蛋机留在左边，字幕"再转一下"挪到它下面，再转一次，不用再投币。新扭蛋从出蛋口滚出来，跳过前面的猫落到队尾，晃三下裂开；已经在场的猫听到动静，头上冒个"!"。最多再扭两次，所以最多三只猫一字排开。同一次扭出来的几只，毛色和项圈不会完全一样。
8. **挑一只**：卡片写的是选中的那只，"扭到了 · 第 2 只"。选中的猫有一圈黄色描边（和店里标"你"的方式一样），脚下的光更亮；刚扭出来的那只默认选中。点另一只猫，或者按 ← →，就换成它：它开心地蹦一下，卡片跟着换。点"就是它了"，没选中的几只"噗"一下化成烟，扭蛋机滑出画面，选中的走到中间坐好。
9. **登记**：走到中间就把名字和外观交给店里的名册。成功以后，一块小金牌从上面落到它的项圈上，"叮"一声，旁边绕一圈星星，接着进黑底引导。

**等你挑的时候，猫不会干坐着**：扭出来的猫每隔几秒做一个小动作：舔爪洗脸、慢眨眼、踩奶、伸懒腰、喵一声、招手、趴下。各做各的，不会一起动。平时是什么表情，也偏爱某几样：睡不醒的爱趴下、伸懒腰，好奇的爱喵，一脸满足的爱踩奶，舌头收不回去的爱舔爪。

**外观**：9 种毛色 × 6 种项圈 × 10 种平时的表情，一共 540 种组合。外观一旦登记就存在名册里，以后每次进店都按它画，不会再变。

**登记失败**：

- 名字在你扭蛋的这一会儿被别的猫先挑走了：见上面"不重名由服务端保证"。
- 网络不好：猫头上出一张小卡片"店门口网不好"，带一个"再试一次"。
- 本机模式下浏览器存不了东西（比如无痕窗口）：写明原因。

## 五、黑底引导 → 掉进店里

黑底，一只猫站在聚光灯里，猫身上描一圈黄边。店里也是用黄边标"你"，所以这一步先让人认得：黄边的就是我。字幕在下方，按键画成像素键帽，按下去的键会亮起来、往下沉一格。右下角"跳过引导"。

1. **走两步**：显示 WASD 和方向键两组键帽，外加一句"或者点一下地面"。用鼠标点，点下去的地方会荡开一圈。聚光灯跟着猫走，字幕下面一根进度条，走满 70 像素就算过。
2. **碰一碰毛线球**：一颗毛线球从上面掉下来，弹两下停在猫旁边。字幕是"走到它旁边"，后面跟着 E、空格两个键帽和一句"或者直接点它"；直接点毛线球的话，猫会自己走过去。离得太远就按 E 的话，字幕抖一下。碰到了，猫扑一下，球滚开，冒几颗星星。
3. **走进光里**：右边从上往下亮起一道光，地上一块光斑，字幕"走进光里 · 店就在那边"。猫走进去就往上一跳，画面慢慢白掉。

**掉进店里**（`js/world4-arrive.js`）：

- 从一片暖白里淡出来，镜头停在一楼咖啡厅的天花板底下，巨树的低枝和叶子就在那儿。
- 你的猫从树叶里掉下来，一路带下几片叶子，镜头跟着它顺着树干往下走。
- 落在树下的环形长凳旁边：先压扁一下，扬起一圈灰，镜头抖一下。旁边的猫吓一跳，回头看，头上冒"!"；你的猫开心地蹦一下。
- 画面上方出大字："1024 猫咖营业中 / 欢迎，芝麻汤圆 / 集齐左上角三个章，就能登记抽奖 · 前台猫在门厅，有事问它"。大字散去以后，左上角的集章卡亮一圈。
- 咖啡厅记成来过，不再出第一次进咖啡厅的那行大字。

这一段放完之前，页面不接玩家的操作。

## 六、再来的时候：认出你

### 怎么认出是你

**这个浏览器记得你**：登记的时候，店里发一张随机令牌，存在这个浏览器里。下次打开，拿令牌问店里"这是谁"，问得到就是"欢迎回来"。令牌每用一次往后顺延，90 天没用才作废。

就这一层。换电脑、换浏览器、清了浏览器数据、开无痕窗口，店里都认不出来，那就是一只新猫。原来那只还在名册里（名字也还占着），只是这个浏览器再也领不回它了。界面上不藏这件事：

- "欢迎回来"卡上的"不是我？换一只新猫"、右下角的"离店"，点了都先说清楚"换了以后就找不回来"。
- 店里存的东西（图鉴、集章卡、交付了几件、站在哪）跟着猫走，新猫从头来。集章卡几分钟就能再集齐；已经登记的抽奖跟着人（工号）走，换了猫也不受影响（见[组织者后台](组织者后台.md)）。

### 安全上还剩什么

- **令牌**：服务端给的是 32 字节随机数，库里只存它的 SHA-256；泄露了库也拿不到能用的令牌。
- **没有"按名字登录"**：店里没有任何一个接口能凭名字拿到一只猫，所以也没有猜暗号、冒领这回事。名字只是显示用的。
- **离店**：店里右下角"离店"，作废这个浏览器的令牌。在公用电脑上玩完可以点一下。
- **同一只猫开了两个窗口**：后开的那个接着玩；先开的那个盖上一层"它在另一个窗口里醒着"，不再存档，点"在这里继续"再把猫接回来。这样两个窗口不会互相覆盖存档。
- **被请出店**：组织者封禁了这只猫，或者这个浏览器记着的令牌已经不认了，店里会盖上一层说明（"这只猫暂时不能进店""找不到你的猫了"），点"好"就回到进店的第一步。

### 再来时的"降生"

| | 第一次来（drop） | 回来（wake） |
|---|---|---|
| 在哪儿出现 | 一楼咖啡厅的毛线巨树下 | 上次离开的地方，哪一层都行（那里走不了，就挪到最近能站的地方） |
| 开场 | 一片暖白淡出去，镜头从树冠往下 | 从黑里一圈圈亮开，圆心就是你的猫 |
| 猫在做什么 | 从树上掉下来，压扁，蹦一下 | 蜷着睡 → 醒来伸个懒腰 → 开心一下；附近的店猫冲它冒一颗心 |
| 大字 | 1024 猫咖营业中 / 欢迎，芝麻汤圆 | 欢迎回来 / 芝麻汤圆 / 上次来是 3 天前 · 解开过 12 颗毛线球 |

## 七、存档

- **存什么**：`g`（图鉴里发现了什么和发现的时间、去过哪些房间、一共解开几颗毛线球、挂进橱窗几件、钓到过哪几种鱼）、`stamps`（集章卡）、`pos`（站在哪）、`arrived`（引导走完了没有）、`visits`。
- **什么时候存**：有变化 3 秒内存一次，没变化 20 秒存一次位置；关页面、切走页面的时候再存一次（请求带 keepalive，页面关了也发得出去）。
- 服务端单只猫的存档上限 48KB。

## 八、两种后端

`js/account.js` 里有两套实现，接口一样，界面不用管用的是哪一套：

- **本机模式**：没有 `config.js`，或者 `api` 空着的时候用，直接双击 `index.html` 打开就是这个模式。店里的名册存在这台浏览器的 localStorage 里，只能保证这台浏览器上不重名。给开发和单机演示用。
- **服务端模式**：`config.js` 里写了 `api`。名字全店唯一，接口见下一节。

`server/server.js` 是参考实现：零依赖，Node 18 以上就能跑，一个进程同时发网页和接口。

```
node server/server.js                      # http://127.0.0.1:1024
PORT=8080 HOST=0.0.0.0 node server/server.js  # 局域网里别的电脑也能开
```

数据在 `server/data/cats.json`，先写临时文件再改名，写到一半断掉也不会把整份写坏。这个文件不进仓库。正式部署要走 https：抽奖登记的姓名、工号、联系方式和后台口令在路上才不是明文。

`config.js` 不进仓库，仓库里放的是 `config.example.js`：

```js
window.CAT1024_CONFIG = {
  api: '/api',              // 服务端地址；空着 = 本机模式
  links: { inner: '' },     // 内源主页等链接（内网地址只写在这里）
  bots: 40,                 // 补位的猫有多少只
};
```

## 九、接口

所有请求和返回都是 JSON。需要身份的接口带 `Authorization: Bearer <令牌>`。

| 接口 | 请求 | 返回 |
|---|---|---|
| `POST /api/names/offer` | `{n, skip:[...]}`（n 最多 12；skip 是这一批不要再给的） | `{names:[...]}`：此刻没有猫用的名字 |
| `POST /api/cats` | `{name, look:{coat, collar, face}}` | 200 `{cat, token}`；409 `{err:'taken'}`；400 `{err:'name'｜'bad'}`（名字不是店里给的那种，或者外观不对） |
| `GET /api/me` | — | 200 `{cat}`（顺带把上次来的时间记成 `prev`）；401 |
| `PUT /api/me/state` | `{state:{...}}`（和原来的合并） | 200 `{ok:true}`；400（太大）；401 |
| `POST /api/me/entry` | `{real, emp, contact}` | 登记抽奖（见[组织者后台](组织者后台.md)）：200 `{entry}`；400 `{err:'bad', field, why}`；403 `{err:'stamps'}`（三个章还没集齐）；401 |
| `POST /api/me/prize-seen` | `{no}` | 200，第几轮的中奖通知看过了，下次不再弹 |
| `POST /api/logout` | — | 200，作废这张令牌 |

`cat` 的样子：`{id, name, look:{coat, collar, face}, created, last, prev, state, prizes, entry}`。`prizes` 是还没看过的中奖通知 `[{no, code, how}]`；`entry` 是自己登记的抽奖信息 `{real, emp, contact, t}`，没登记是 `null`。这两样只发给猫自己。

联机用的是另一条通道（`/ws` 上的 WebSocket），见[联机](联机.md)。组织者用的接口在 `/api/admin/*`，见[组织者后台](组织者后台.md)。
