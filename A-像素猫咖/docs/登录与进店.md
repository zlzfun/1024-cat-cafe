# 登录与进店

打开网页到你的猫出现在店里，中间这一段叫"进店"。第一次来的人要在这里给猫取名字、扭到一只猫、学会怎么走和怎么碰东西；来过的人要被认出来，领回同一只猫。

整段流程有两个要求：

- **别像登录页**。这个活动推的是 Clowder AI，所以进店从 Clowder AI 自己的网页开始：你在它的"添加成员"里登记一只新猫，页面一点点变成像素，你就进了猫咖。
- **认得出人，也防得住冒充**。店里的名字不能重，你的猫换台电脑还是那只，别人报你的名字也领不走。

## 一、流程

| 情况 | 经过 | 结尾 |
|---|---|---|
| 第一次来 | 加载 → Clowder AI 网页动画 → 取名 → 扭蛋 → 刻暗号（登记）→ 黑底引导 | 从毛线巨树上掉进店里 |
| 来过，同一台电脑 | 加载 → 加载页上一张"欢迎回来"的卡（4.5 秒后自己进店） | 在上次离开的地方醒来 |
| 来过，换了电脑 | 加载 → 网页动画 → 取名那一步点"来过了？领回我的猫" → 名字 + 暗号 | 醒来 |
| 这台电脑记着别人的猫 | "欢迎回来"卡上点"不是我？换一只猫" → 直接到取名（不再放网页动画） | 看是新猫还是领回 |
| 登记完还没走完引导就关了页面 | 下次打开直接从黑底引导接着走 | 掉进店里 |

## 二、加载页

深色底，正中"1024 猫咖营业中"。下面一只小白猫追着一颗毛线球往右跑，线球滚过的地方留下一根红线，这根线就是进度条。线下面一行小字说正在做什么：把猫叫醒、搬桌椅、铺地板刷墙、把毛线球装进篮子、给巨树缠毛线、擦橱窗、点灯、看看你是不是来过。线走完，小猫扑上去。

- **进度是真的**：脚本下载完算八成，建好整家店（地图、店猫、补位的猫）到八成五，问完账号到头。脚本并行下载、按顺序执行。
- **不会一闪而过**：进度条最快也要走一秒左右，不会闪一下就没了；真正慢的时候就停在当前那一步等着。
- **出错不白屏**：有文件没加载出来，就写明是哪一个，旁边给一个"再试一次"。
- 来过的人，加载完就在这里出"欢迎回来"的卡片：你的猫（在慢眨眼），名字，毛色和项圈，上次是什么时候来的，解开过几颗毛线球。按钮"进店"上有一根慢慢走满的线，走满就自己进店；在卡片上点一下，线就停下来等你。卡片上还有一个"不是我？换一只猫"。

## 三、Clowder AI 网页 → 取名

### 动画（约 8.5 秒，右下角可以跳过）

照着 Clowder AI 网页端（`packages/web`，浅色主题）的真实布局、颜色和文案来画。logo 直接用项目里的 SVG 路径。人类不出场：对话里说话的全是猫。

| 时间 | 画面 |
|---|---|
| 0～2 秒 | 首页。左边一列图标，接着是对话列表（"大厅"选中），右边是大厅的对话。斑斑早上说过"今天的咖啡豆到了"；接着宪宪说"店里今天要来一只新猫"，砚砚说"先在成员里登记一下，名字别和别的猫重了"，烁烁说"我去把欢迎横幅挂上 ✨"。每句话出来之前，输入框上方先出"猫猫正在回复中…" |
| 2～3 秒 | 光标移到左下角的齿轮"设置"点一下，页面换成"设置 · 成员与运行时"：六只店猫的成员卡片，右上角"+ 添加成员" |
| 3～4 秒 | 点"+ 添加成员"，后面的页面变暗变模糊，弹出"添加成员"：成员模板、身份信息（名称、昵称、显示后缀、角色描述、头像、背景色……）|
| 4～6 秒 | 光标点进"角色描述"，敲下"1024 猫咖的新猫"；再点进"名称"，这一格亮起焦点框，光标闪 |
| 6～8.5 秒 | 整个页面一步步变成像素：先是 2、3、4 像素一格，颜色换成店里的调色板，带一点抖动；然后别的东西碎成 6 像素的块，从四周往里一块块掉下去、暗掉。只剩"名称"这一格，它从弹窗里挪到画面正中，边框从圆角变成店里对话框那种外深内浅的像素窗框。最后它又一步步变清楚，光标变成一只粉色的像素猫爪 |

动画停下的那一刻，画布上那一格和网页上的真输入框在同一个位置、长得一样，接着换成可以打字的真输入框。系统开了"减少动态效果"时，整段动画不放，直接到取名。

### 取名

- 标题"给你的猫取个名字"，下面就是那个输入框，打开就能直接打字。
- 边打字边查：格式不对当场说哪里不对；格式对了，停手 0.2 秒去问店里的名册，回来写"✓ 还没有猫叫这个名字"或"店里已经有一只「团子」了"。
- 下面一排建议名字（只给还没被占的），"换一批"再来六个。名字被占了，建议就换成它的几个变体：小团子、团子二号、团子喵、大团子、团子酱。
- 名字被占的那一行还有一个"这就是我的猫"，点了转到"领回"，名字替你填好。
- "就叫它"要等查过、确认能用才亮；回车等于点它。

**名字的规矩**（前端和服务端是同一份代码：`js/account.js` 的 `Account.rule`）：

- 先做 NFKC 规范化、去掉首尾空白；中间不能有空格。
- 只能用文字、字母、数字，外加 `·` `_` `-`。
- 长度按显示宽度算：汉字算 2，字母数字算 1，总共 2～16，也就是 1～8 个汉字或者 2～16 个字母。
- 店猫的名字（宪宪、砚砚、烁烁、小狸花、斑斑、金哥、前台猫）不能用。另外留给店里用的：你、我、人类、店长、店猫、猫猫、管理员、系统、猫猫咖啡馆、clowder、admin 等。
- 名字里含有"管理员""官方""系统""客服""组织者""主办方"的也不能用，免得冒充办活动的人。
- 服务端模式下，组织者还能在后台维护一份屏蔽词（见[组织者后台](组织者后台.md)），名字去掉空格标点以后含有其中的词，就提示"这个名字不太合适，换一个吧"。
- **判重**按 NFKC + 小写比，全角半角、大小写都算同一个名字。简体和繁体（团子 / 團子）目前算两个名字。

## 四、扭蛋 → 刻暗号 → 登记

像素画布的放大倍数按窗口高度定（一个像素 3～6 个屏幕像素），深色底，只有聚光灯下亮着。

1. **扭蛋机掉下来**：一台猫头形状的扭蛋机从上面落下，弹两下落稳。玻璃罩是猫头，顶上一块红帽子带两只耳朵；罩子里十几颗扭蛋，颜色就是店里的六种项圈色。机身上写着 1024。
2. **名字变成硬币**：刚才取的名字从输入框的位置飞向投币口，越飞越小，"叮"一声投进去。
3. **转旋钮**：字幕"转一下旋钮"，旋钮一直轻轻晃着。按 E、空格，或者在画面上点一下都行。旋钮转一圈，咔哒咔哒响，罩子里的扭蛋跟着晃，一颗掉进出蛋口，翻盖打开，扭蛋骨碌碌滚出来。
4. **扭蛋蹦到跟前**：它一跳一跳地蹦到画面中间，越蹦越大；扭蛋机往左边让开。扭蛋晃三下，一下比一下晃得厉害。
5. **裂开**：上半个壳转着圈飞出去，下半个沉下去淡掉，光线四射、碎屑乱溅，你的猫开心地蹦一下，然后端端正正坐好。
6. **卡片**："扭到了"，名字，毛色 · 项圈颜色，平时是什么表情（比如"舌头老是忘了收"）。两个按钮："就是它了"，和"再扭一次（还有 2 次）"。再扭的话，猫"噗"一下消失，扭蛋机挪回中间，再转一次，不用再投币。
7. **刻暗号**：扭蛋机滑出画面。猫头顶上浮着一块金色的圆形项圈牌，上面四个空格。右边的卡片写着"给它的项圈牌刻个暗号：换电脑、换浏览器的时候，报上名字和这四个图案，就能把它领回来。记住它们。"下面是九个图案：小鱼干、毛线球、铃铛、爪印、咖啡杯、老鼠玩具、纸箱、猫薄荷、月亮。按顺序点四个，也可以按数字键 1～9；每点一个，牌上就刻上一个。可以"重来"。
8. **登记**：点"刻好了"，把名字、暗号、外观一起交给店里的名册。成功以后，项圈牌闪一下光，缩成一个小金点挂到猫的项圈上，旁边绕一圈星星。

**外观**：9 种毛色 × 6 种项圈 × 10 种平时的表情，一共 540 种组合。再扭时，不会连着扭出毛色和项圈都一样的。外观一旦登记就存在名册里，以后每次进店都按它画，不会再变。

**登记失败**：

- 名字在你扭蛋的这一会儿被别的猫抢先用了：回到取名，写着"刚刚有别的猫用了「团子」，换一个吧"。扭到的外观和刻好的暗号都留着，换好名字直接登记，不用再扭一遍。
- 网络不好：卡片上写"店门口网不好，等一下再点一次"，暗号还在。
- 本机模式下浏览器存不了东西（比如无痕窗口）：写明原因。

## 五、黑底引导 → 掉进店里

黑底，一只猫站在聚光灯里，猫身上描一圈黄边。店里也是用黄边标"你"，所以这一步先让人认得：黄边的就是我。字幕在下方，按键画成像素键帽，按下去的键会亮起来、往下沉一格。右下角"跳过引导"。

1. **走两步**：显示 WASD 和方向键两组键帽，外加一句"或者点一下地面"。用鼠标点，点下去的地方会荡开一圈。聚光灯跟着猫走，字幕下面一根进度条，走满 70 像素就算过。
2. **碰一碰毛线球**：一颗毛线球从上面掉下来，弹两下停在猫旁边。字幕是"走到它旁边"，后面跟着 E、空格两个键帽和一句"或者直接点它"；直接点毛线球的话，猫会自己走过去。离得太远就按 E 的话，字幕抖一下。碰到了，猫扑一下，球滚开，冒几颗星星。
3. **走进光里**：右边从上往下亮起一道光，地上一块光斑，字幕"走进光里 · 店就在那边"。猫走进去就往上一跳，画面慢慢白掉。

**掉进店里**（`js/world4-arrive.js`）：

- 从一片暖白里淡出来，镜头停在毛线巨树的树冠上。
- 你的猫从树叶里掉下来，一路带下几片叶子，镜头跟着它顺着树干往下走。
- 落在树下的石板地上：先压扁一下，扬起一圈灰，镜头抖一下。旁边的猫吓一跳，回头看，头上冒"!"；你的猫开心地蹦一下。
- 画面中间出大字："1024 猫咖营业中 / 欢迎，团子 / 你落在了毛线巨树下 · 前台猫在前厅，有事可以问它"。
- 训练营的第一步"走两步"直接记成完成；中庭记成来过，不再放第一次进中庭的镜头。

这一段放完之前，页面不接玩家的操作。

## 六、再来的时候：认出你、同一只猫、防冒充

### 怎么认出是你

一共三层，前两层现在就有：

1. **这台浏览器记得你**：登记或领回的时候，店里发一张随机令牌，存在这台浏览器里。下次打开，拿令牌问店里"这是谁"，问得到就是"欢迎回来"。令牌 90 天没用就作废。
2. **换电脑用名字 + 暗号**：暗号是九个图案里按顺序挑四个，可以重复，一共 6561 种。
3. **（推荐正式活动用）公司统一登录**：接进公司的统一登录，身份就是工号，天然不会重复，别人也冒充不了，暗号这一步可以去掉。抽奖本来就要知道谁是谁，接了统一登录，领奖也不用另外核对。这一层要看内网环境再做，接的地方已经留好了（见"十、还没做的"）。

### 同一只猫

外观（毛色、项圈、表情）、名字、店里的记录（图鉴、训练营、解了几颗球、集章卡、上次站在哪），都存在店里的名册上，不存在"这台电脑"上。换哪台电脑领回来，都是同一只猫，站在它上次离开的地方。

### 防冒充

- **暗号只存散列**：服务端用 scrypt，每只猫一份随机盐，比对用恒定时间比较。本机模式用 PBKDF2，浏览器不支持时退回一份自带的 SHA-256 多轮。
- **输错有上限**：同一个名字连错 5 次，锁 10 分钟。同一个 IP 10 分钟里错满 30 次，也先歇一会儿。界面上写"暗号不对，还能再试 N 次"和"试错太多次了，N 分钟以后再来"。
- **令牌**：服务端给的是 32 字节随机数，库里只存它的 SHA-256；泄露了库也拿不到能用的令牌。
- **离店**：店里右下角"离店"，作废这台浏览器的令牌，下次要报名字和暗号。在网吧、公用电脑上玩完点一下。
- **同一只猫开了两个窗口**：后开的那个接着玩；先开的那个盖上一层"它在另一个窗口里醒着"，不再存档，点"在这里继续"再把猫接回来。这样两个窗口不会互相覆盖存档。联机时换一台电脑也一样：后连上的那个接着玩。
- **被请出店**：组织者封禁了这只猫、重置了它的暗号，或者这台电脑记着的登录过期了，店里会盖上一层说明（"这只猫暂时不能进店""暗号换过了""要重新进店"），点"好"就回到进店的第一步。
- **强度**：6561 种，每个名字 10 分钟只能试 5 次，一个一个试平均要试好几个月。对一个活动小游戏够用了。它挡不住的是：被人看见你点了哪四个，或者你把暗号告诉了别人。所以正式活动推荐接统一登录。

### 忘了暗号

自己找不回来。可以找组织者：在[组织者后台](组织者后台.md)的名册里点这只猫的"重置暗号"，后台会画出新的四个图案，由组织者转告；或者在服务器上运行 `node server/server.js reset 团子`（先停掉正在跑的服务）。两种办法都会让旧令牌全部作废。

### 再来时的"降生"

| | 第一次来（drop） | 回来（wake） |
|---|---|---|
| 在哪儿出现 | 毛线巨树下 | 上次离开的地方（那里走不了，就挪到最近能站的地方） |
| 开场 | 一片暖白淡出去，镜头从树冠往下 | 从黑里一圈圈亮开，圆心就是你的猫 |
| 猫在做什么 | 从树上掉下来，压扁，蹦一下 | 蜷着睡 → 醒来伸个懒腰 → 开心一下；附近的店猫冲它冒一颗心 |
| 大字 | 1024 猫咖营业中 / 欢迎，团子 | 欢迎回来 / 团子 / 上次来是 3 天前 · 解开过 12 颗毛线球 |

## 七、存档

- **存什么**：`g`（图鉴里发现了什么和发现的时间、训练营走到哪、去过哪些房间、一共解开几颗毛线球）、`stamps`（集章卡）、`pos`（站在哪）、`arrived`（引导走完了没有）、`visits`。
- **什么时候存**：有变化 3 秒内存一次，没变化 20 秒存一次位置；关页面、切走页面的时候再存一次（请求带 keepalive，页面关了也发得出去）。
- 服务端单只猫的存档上限 48KB。

## 八、两种后端

`js/account.js` 里有两套实现，接口一样，界面不用管用的是哪一套：

- **本机模式**：没有 `config.js`，或者 `api` 空着的时候用，直接双击 `index.html` 打开就是这个模式。店里的名册存在这台浏览器的 localStorage 里，只能保证这台浏览器上不重名。给开发和单机演示用。
- **服务端模式**：`config.js` 里写了 `api`。名字全店唯一，接口见下一节。

`server/server.js` 是参考实现：零依赖，Node 18 以上就能跑，一个进程同时发网页和接口。

```
node server/server.js                      # http://127.0.0.1:1024
PORT=8080 HOST=0.0.0.0 node server/server.js  # 局域网里别的电脑也能开
```

数据在 `server/data/cats.json`，先写临时文件再改名，写到一半断掉也不会把整份写坏。这个文件不进仓库。正式部署要走 https：暗号在路上是明文的四个数字。

`config.js` 不进仓库，仓库里放的是 `config.example.js`：

```js
window.CAT1024_CONFIG = {
  api: '/api',              // 服务端地址；空着 = 本机模式
  links: { inner: '' },     // 内源主页等链接（内网地址只写在这里）
  bots: 40,                 // 补位的猫有多少只
};
```

## 九、接口

所有请求和返回都是 JSON。需要身份的接口带 `Authorization: Bearer <令牌>`。

| 接口 | 请求 | 返回 |
|---|---|---|
| `POST /api/names` | `{names:[...]}`（最多 24 个） | `{results:{名字:{ok, taken?, why?}}}` |
| `POST /api/cats` | `{name, code:[4 个 0～8], look:{coat, collar, face}}` | 200 `{cat, token}`；409 `{err:'taken', why}`；400 `{err:'name'｜'bad', why?}` |
| `POST /api/login` | `{name, code}` | 200 `{cat, token}`；401 `{err:'code', left}`；404 `{err:'none'}`；429 `{err:'lock', wait:秒}`；403 `{err:'ban'}`（被组织者封禁） |
| `GET /api/me` | — | 200 `{cat}`（顺带把上次来的时间记成 `prev`）；401 |
| `PUT /api/me/state` | `{state:{...}}`（和原来的合并） | 200 `{ok:true}`；400（太大）；401 |
| `POST /api/me/prize-seen` | `{no}` | 200，第几轮的中奖通知看过了，下次不再弹 |
| `POST /api/logout` | — | 200，作废这张令牌 |

`cat` 的样子：`{id, name, look:{coat, collar, face}, created, last, prev, state, prizes}`。`prizes` 是还没看过的中奖通知 `[{no, code, how}]`（见[组织者后台](组织者后台.md)）。

联机用的是另一条通道（`/ws` 上的 WebSocket），见[联机](联机.md)。组织者用的接口在 `/api/admin/*`，见[组织者后台](组织者后台.md)。
