# 组织者后台

给办活动的人用的一页：看店里有哪些猫、谁集齐了三个章、抽奖、导出名单、帮忘了暗号的人重置、处理不合适的名字。只在服务端模式下有。

地址是网页后面加 `admin.html`，比如 `http://127.0.0.1:1024/admin.html`。

## 一、口令

- 服务端第一次启动时生成一个随机口令，存在 `server/data/admin.key`，并打印在启动日志里。也可以用环境变量 `ADMIN_KEY` 指定。
- 后台页面本身不含任何秘密，所有数据都要带着口令去服务端取。口令只存在这个浏览器标签页里（关掉就要重新输）。
- 同一个地址 10 分钟内口令错 10 次，先歇一会儿。服务端放在反向代理后面时，所有请求看起来都来自代理，一个人输错就会把大家都锁住：这时用 `TRUST_PROXY=1` 启动，服务端改按代理追加在 `X-Forwarded-For` 末尾的地址计数（只在确实有代理时这么开，否则这个头可以被伪造）。
- 数据目录（口令、名册都在里面）永远不对外发，哪怕用 `DATA_DIR` 把它放在了网页目录里面。
- 名册里有些数（来过几次、解开几颗）是玩家自己的存档交上来的：服务端先压成非负整数，后台页面插进网页的每个值再转义一次，存档里写什么都不会在后台页面里执行。
- 正式部署要走 https，口令和暗号在路上才不是明文。

## 二、页面上有什么

### 概况

一行数字：登记了多少只猫、此刻在线、今天来过、集齐三个章（有抽奖资格）、今天全店挂了几件、毛线巨树一共挂了几件。

### 抽奖

- **资格**：集章卡三个章都盖了：解开一颗毛线球（挂进橱窗）、逛过内源主页、看过官网或 GitHub。一只猫一次资格，和玩得好不好无关。封禁的猫不算。
- **抽**：填抽几只、要不要排除已经抽中过的、一句"怎么领奖"（比如"在活动群里私聊小助手"），点"抽"。服务端用加密随机数从有资格的猫里抽，结果存下来，页面上列出每一轮抽中了谁。
- **领奖码**：每只被抽中的猫有一个 6 位的领奖码。它下次进店（或者正在店里），画面上会弹出"你被抽中了"，写着领奖码和怎么领奖。组织者拿到领奖码，在后台对一下是不是这一只。名字谁都能冒充，领奖码只有这只猫的主人看得到。
- **导出**：有资格的名单、每一轮的中奖名单，都能导出成 CSV（带 BOM，Excel 直接打开不乱码）。

### 名册

一张表，每只猫一行：像素头像、名字、登记时间、最近来过、来过几次、解开几颗毛线球、服务端记到它挂过几件、三个章、是否在线。能按名字搜，能只看有资格的。

每一行能做三件事：

| 操作 | 做什么 |
|---|---|
| 重置暗号 | 换一组随机的四个图案，显示在后台上，由组织者转告本人；它在别处登着的都会被登出 |
| 改名 | 名字不合适时用。新名字同样要守取名的规矩、不能和别的猫重名。它正在店里的话，自己和别人的画面上马上换成新名字 |
| 封禁 / 解封 | 封禁以后进不了店，正在店里的会被请出去；名字仍然占着，别人不能拿来用 |

### 屏蔽词

一个文本框，一行一个词。取名、改名时，名字里（去掉空格和标点以后）含有其中任何一个，都会被拒绝，提示"这个名字不太合适，换一个吧"。存在 `server/data/blocked.txt`，不进仓库。

另外，程序里固定挡掉容易冒充组织者的名字：包含"管理员""官方""系统""客服""组织者""主办方"的名字不能用。这一条前后端都会查。

## 三、集章卡的可信程度

三个章是在玩家自己的浏览器里盖的，再随存档交给服务端，懂技术的人能改。为此后台多列了一栏"服务端记到的挂进橱窗次数"：联机时，每挂一件都会经过服务端。盖了"解球"章、服务端却一次都没记到的，名册里会标出来，组织者可以自己判断（离线玩的、联机之前玩的也会这样）。

对一个文化节的小游戏，这样就够了。要更严，得接公司统一登录，并把"逛内源主页"改成由内源主页那边回调确认。

## 四、接口

全部要带请求头 `X-Admin-Key: <口令>`。

| 接口 | 请求 | 返回 |
|---|---|---|
| `GET /api/admin/stats` | — | 概况的几个数 |
| `GET /api/admin/cats` | — | `{cats:[{id, name, look, created, last, visits, balls, hangs, stamps, eligible, online, banned, flag}]}` |
| `POST /api/admin/reset` | `{id}` | `{code:[4 个 0～8]}` |
| `POST /api/admin/rename` | `{id, name}` | `{ok}`；400/409 同取名 |
| `POST /api/admin/ban` | `{id, on}` | `{ok}` |
| `GET /api/admin/draws` | — | `{draws:[{no, t, n, pool, how, winners:[{id, name, code}]}]}` |
| `POST /api/admin/draw` | `{n, fresh, how}` | 这一轮的结果 |
| `GET /api/admin/blocked` | — | `{words:[...]}` |
| `PUT /api/admin/blocked` | `{words:[...]}` | `{ok}` |
| `GET /api/admin/export?what=eligible｜all｜draw&no=1` | — | CSV 文件 |

玩家那一侧多了一个字段：`GET /api/me` 返回的 `cat` 里，被抽中过的会带 `prizes:[{no, code, how}]`；玩家看过以后调 `POST /api/me/prize-seen`，下次就不再弹。

## 五、代码

| 文件 | 做什么 |
|---|---|
| `admin.html` | 后台页面（和店里同一套颜色、字和像素边框） |
| `js/admin.js` | 后台页面的逻辑 |
| `server/admin.js` | 后台接口、抽奖、导出、屏蔽词 |

在服务器上也还能用命令重置暗号：`node server/server.js reset 团子`（先停掉正在跑的服务）。
