# 1024 猫咖 · 特性地图（v2）

这次活动的目的，是让人认识猫猫咖啡馆（Clowder AI），然后愿意去它的主页、GitHub 和内源主页看一看。所以店里的每一样东西、每一颗毛线球，最好都能对应上猫猫咖啡馆的一项真实能力。

这份文档回答三个问题：
- 要介绍哪些特性？
- 每项特性放在店里哪儿、怎么讲？
- 接下来还可以做什么？

"v4" 指 `scene-v4.html` 里已经做好的部分。特性的说法以仓库 README、`docs/TIPS.md` 和 `docs/features/` 为准。

## 怎么讲：三层

1. **看得见：一样东西。** 比如图书馆（长期记忆）、合并门禁（门禁和跨模型 review）、星星罐子（拉闸词）、工具墙（Skills 和 MCP 工具）。人在店里逛的时候先看到它，碰一下就知道是什么。
2. **做一遍：一类毛线球。** 比如"派单"让人挑一只猫 @ 它，"走流程"让人把测试、CI、Review、合并亲手走一遍。做过一次，比读十遍说明书记得牢。
3. **讲一句：一条 Tips。** 出现在对话框底部、"新发现"提示、鼠标悬停卡片里，每条都带"了解更多"的链接。一次只讲一件事，不做大段说明。

几条原则：
- **先玩后讲。** Tips 出现在玩的当下，不在进店前堆一屏文字。
- **直接说"猫猫咖啡馆"。** 讲特性时不说"真的猫咖"，直接说"猫猫咖啡馆会……"或"实际上，猫咖会……"。介绍里不写"按 E"：按键只出现在底部提示条和按键说明里。
- **用猫咖自己的词。** 毛线球、球权、猫粮、拉闸词、图书馆、训练营、@owner。玩家在店里学会了这些词，用起猫猫咖啡馆来会觉得眼熟。
- **只讲做完了的。** 进行中的特性可以做成物件，但 Tips 里不承诺，并在题库里标出来。
- **人类不出场。** 人只留下便签和回信，这正好对上猫猫咖啡馆的"你（operator）只管愿景、决策和反馈"。
- **画面要有主次。** 全店只有一样巨物：毛线巨树，从一楼咖啡厅的地面长出来，穿过二楼的天井，树冠在屋顶上，三层楼高。每间房再有一样主角，比别的东西大一号，放在房间正中或者正对门口，脚下用地毯、台子或者另一种地面托住（门厅的接单毯和大毛线篮、舞台的 1024 背板、吧台的大咖啡机、工坊的合并门禁……）；配角两三样一组；能上墙的都上墙。每间房一种地面、一种墙，门洞上挂招牌，左上角写着在哪一层哪一间。
- **给人停下来的地方。** 几处"看风景"：坐下来画面切到一张特写（你的猫的背影和它看着的东西），安静，不讲特性，Esc 就回来。特写和店里是同一套像素（一个像素一格、深色描边、抖动过渡，不放大），每一处有一个记得住的东西：穿毛线套的街和满车猫的电车、会连成猫座的星星、海边的灯塔和毛线球热气球、够鱼的小游戏。
- **引导交给店里的角色，不往画面上贴记号。** 东西头上不冒问号、不描虚线框，有没有玩到只记在图鉴里（图鉴像成就列表：解锁的打 ✓ 排在前面，没解锁的打 ✗、只留名字）。想知道玩什么，问前台猫；店猫偶尔搭一句话；鼠标移到能玩的东西上变成猫爪。这和猫猫球定的规矩一致：安静优先，不抢焦点，主动开口要有频率上限（F229 里 Clippy 的反面教训）。

## 还没放进店里的（按优先级）

1. **委托看板点开是毛线球列表。** 按 doing / blocked / todo / done 列出全店的球：谁在解哪一颗、哪颗卡住了。讲的是毛线球任务板（F160）和任务中心（F049）。
2. **猫头上的"本轮计划"。** 店猫接了球以后，头上冒一个小清单，一项项打勾。对应猫猫祟祟（F250，已完成）。
3. **猫粮看板。** 吧台那头喂食器旁边一块小黑板，写"今日猫粮"。解的球越多，猫粮用得越多。对应猫粮看板（F051，进行中）。
4. **投票机。** 快捷短语加"投个票"，附近的猫围过来举爪。对应 /vote（F079）。
5. **墨墨当图书管理员。** 第七只店猫（梵花猫 · Kimi），常驻图书馆阅读桌，管"查记忆"那类球。
6. **跨家族 review 的画面。** review 时两只猫之间连一道线，写着"Claude 写 · GPT 审"。
7. **每只店猫一种叫声。** 声音打开时，六只店猫的"喵"各不相同。对应每只猫独立声线（F103）。
8. **更多"看风景"。** 查记忆翻到的那一页做成一张书页特写；工坊里趴在键盘上看代码滚动；大毛线团解开的那一刻，一张全员合照。

## 接联机时要注意

- **任务跟着球走，由服务端记。** 谁在解哪一题、走到哪一步、选错过哪些，都记在球上。玩家掉线再回来，便签还在。
- **毛线巨树是全店共用的进度。** 树上挂几件、满树金光过几次，由服务端记，所有人看到的是同一棵树。
- **看风景是每个人自己画面里的事。** 别人看到你的猫坐在窗台上、树顶上，不会被切走画面。
- **前台猫也只有一只。** 带路是每个人自己画面里的事：你看到它在给你带路，别人看到它还坐在前台。
- **店猫只有六只，一百个玩家会同时 @ 它。** 需要排队：被 @ 的店猫头上显示"排第 3"。或者让店猫"分身"：每个玩家看到的那只是自己的，别人看到它在原地。
- **协作球的帮手可以是真人。** 喊"来帮忙！"时先叫附近的真人玩家，没人来再补机器人。
- **题库放在服务端。** 方便活动中途加题、下题，也方便统计哪些题错得最多（那些就是最值得讲的特性）。
