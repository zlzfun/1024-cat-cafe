# 交互目录

店里能碰的东西，一共 119 样，按楼层、房间排。这份是从游戏里的数据（`js/world4-guide.js` 的 `GUIDE`，也就是图鉴的内容）直接生成的，和游戏里看到的一字不差；改了数据以后重新生成一次。楼梯不算在里面（它是房子的一部分，走进楼梯口就上下楼）；彩蛋也不在这里（找到了才知道，见[店内设计](店内设计.md)第四节）。

- **前提**：要满足才能玩的条件，没有就空着。
- **提示**：悬停卡上名字下面那一行。只有几样复杂的、和主线有关的才有；别的悬停卡只写名字，会发生什么玩了才知道。
- **会怎样**：玩了以后发生什么（悬停卡上不写，第一次玩到时"新发现"里写，图鉴里也有）。
- **对应的特性**：它讲的是猫猫咖啡馆的哪项能力（新发现、图鉴里会写这一句）。
