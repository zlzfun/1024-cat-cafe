# 交互目录

店里能碰的东西，一共 78 样，按楼层、房间排。这份是从游戏里的数据（`js/world4-guide.js` 的 `GUIDE`，也就是图鉴的内容）直接生成的，和游戏里看到的一字不差；改了数据以后重新生成一次。楼梯不算在里面（它是房子的一部分，走进楼梯口就上下楼）。

- **前提**：要满足才能玩的条件，没有就空着。
- **会怎样**：玩了以后发生什么。
- **对应的特性**：它讲的是猫猫咖啡馆的哪项能力（图鉴、悬停卡、新发现里都会写这一句）。
