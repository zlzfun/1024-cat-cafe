猫猫咖啡馆 · 风格样页

六组不同的视觉风格，主题都是「你是一只猫，在咖啡馆里接人类的毛线球」。每组都能直接玩：走动、躺沙发、解开毛线球。为了一次看全，每组演示的解球方式也不同（选择、填空、动作、拖拽、传球链）。风格和玩法可以拆开重新组合。

组一句话气质怎么走动本组演示的解球方式上手门槛实现成本
A 像素 RPG怀旧游戏，"真的在玩"方向键 / 点地板选择题 + @猫传球中中
B 等距小屋清新治愈，像精致的模拟经营点地板寻路填空题低中高
C 绘本手绘温暖叙事，像在翻一本绘本点哪走哪（横向）动作型选择（治愈日常）最低中
D 终端字符1024 程序员梗，极客浪漫方向键 / hjkl / 点地图选择题 + 命令式传球高（非技术同事）低
E 软糯黏土Q 萌潮玩，一眼想捏点地板（单排舞台）把毛线球拖给被 @ 的猫最低低中
F 剖面楼层整栋店都在营业，热闹点楼层，自动走楼梯多猫协作传球链低中

所有样页都是纯前端、单文件、无外部依赖，本地双击就能打开。样页里的 NPC 都有明确标注；F 组另外演示了"真人玩家"和 NPC 的区分。

STYLE A

像素 RPG

画面

16-bit 俯视角，暖木地板、粉色沙发、黑板写着 CAT CAFE 1024。美术全部由代码逐像素绘制。

试试

  • 先点一下画面，用方向键走，或者直接点地板
  • 走上沙发会躺平
  • 桌上的毛线球：按空格或点它
  • 解开后会冒出一颗 @砚砚 的球，传给它

考量

游戏感最强；但对没玩过游戏的同事，"这是个游戏"本身就是门槛。

STYLE B

等距小屋

画面

45° 等距视角的小房间，薄荷墙、奶油地砖、柔和阴影，像一个可以转动的迷你模型。

试试

  • 点任意地砖，猫会自动绕开家具走过去
  • 点沙发躺一会儿
  • 点桌上闪烁的毛线球，做一道 git 填空题

考量

好看又好懂，纯鼠标即可。家具多了以后，遮挡排序和统一的美术风格需要花功夫维护。

STYLE C

绘本手绘

画面

纸纹、抖动的蜡笔线、水彩晕染，窗外在下雨，楷体旁白像绘本的配文。

试试

  • 点地板左右走，点沙发团成球
  • 点窗户切换晴雨，点吊灯开关灯
  • 点人类头顶的小乌云，用"蹭蹭 / 叼热可可 / 坐键盘"来安慰他

考量

情感浓度最高，也最不像游戏，最适合非玩家。手绘滤镜在低配电脑上会稍微吃性能，而且只能沿一条线走动。

STYLE D

终端字符

画面

咖啡色终端，用字符画出整间店；你就是那个 @。右侧 events.log 实时滚动剧情。

试试

  • 方向键 / WASD / hjkl 移动，也可以点地图上任意字符
  • 撞一下红色闪烁的 *，按 1/2/3 作答
  • 第二颗球用 pass --to 烁烁 传出去

考量

最贴 1024 程序员节，也最轻量。但可爱度低，非技术同事可能看不懂。可以只做成彩蛋模式。

STYLE E

软糯黏土

画面

奶油粉背景，黏土质感的圆团猫和家具，内外双层阴影营造出"捏出来"的手感。

试试

  • 把中间的毛线球拖给标签上 @ 的那只猫
  • 拖错了，猫会告诉你该给谁
  • 点猫会弹一下，点沙发会躺下

考量

几乎不用教，拖一下就懂，"传球"最直观。代价是自由走动很弱，只有一排舞台，同屏容纳不了太多猫。

STYLE F

剖面楼层

画面

夜晚的两层小楼剖面，扁平撞色。吧台、工位、沙发、楼梯一屏看全，人类头顶挂着待解的毛线球。

试试

  • 点任意楼层的地板，猫会自己走楼梯
  • 点 2F 小林：你写周报，传给烁烁配图，再交付（三步传球链）
  • 点 1F 小周：@砚砚 的球，传给砚砚

考量

最能表现"多人 + NPC + 协作"，热闹感强。但信息密度高，窄屏上字会偏小。
